## 1. Why an Agent Skill

A comparison is needed at one moment: a structure is hard to see, and more than one way of showing it could work. The agent knows the moment by the question it faces. An Agent Skill is read at that moment, whole, through the Pulled Channel.

Nothing else would bring it up then. No file is touched that a Paths Rule could load on, and nothing in a record names the moment.
