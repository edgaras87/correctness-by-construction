# Commit plan: the simulation's short words

## Summary — the state after all commits

`temp/system-repo-change-simulation.md` writes nine of the Common Ground Problem's Defined Terms by a short word, capitalized: Change, Record, Update, Reading, Version, Attention Note, Register, Update Note and Copy. A table at the top of the file gives each short word and the Defined Term it stands for, and says they are short forms of this file, not Names. The file is about 990 words shorter, and a sentence no longer holds one long name four times. The problem file keeps the long names, and nothing in it changes.

## Commits

**1. `docs(agent): add commit plan, temp's short words`**
This plan.

**2. `docs: temp's simulation takes nine short words`**
The table, and every long name replaced by its short word, by script, longest name first. The table and the replacement are one commit: either alone leaves the file saying two things. Left as they are: the one title quoted from the problem file, *A System Kit Attention Note*, and the table's own right column. The count of each name before, and of each short word after, is shown at the boundary, with the headings counted before and after.

**3. `docs: temp's copy in lowercase becomes Copy`**
"The copy" and "copies" in lowercase stand for System Kit Copy about 100 times. Each use is read. One that means a System Kit Copy becomes Copy; the verb, and a copy of anything else, stay.

**4. `docs: temp's short words, each sentence read`** (provisional)
Every changed sentence is read for what it now claims. Three kinds are looked for: "Change" beside a plain "change", the System Kit's own or the verb; "Change" where the first part's name is meant; a short word that opens a sentence, where the capital says nothing. A sentence that can be misread is reworded. If none is found, this commit does not exist, and the close says so.

**5. `docs(agent): close commit plan, temp's short words`**
Deletes this file. Its body says what diverged, and the file's word count before and after, by script.

## Decisions taken inside this plan

- **No article in a short word.** It is Change, never "The Change" or "A Change". The article follows the sentence, in lowercase: a Change, the Change, each Change, Changes. A fixed article would break the plural and "each".
- **The two notes keep two words,** Attention Note and Update Note. "Note" alone meant two things until 2026-11-12.
- **One word, where writing rule 9 asks two or more for a Name.** The table says they are short forms of one file, each standing for a Defined Term that keeps its full Name in the problem file.
- **One commit for the nine names, not one each.** The replacement is exact text for exact text, counted by script. The terms went in one per commit because each use had to be read; here only commit 3's uses do.
- **Step headings change too,** since they hold the long names. Nothing outside the file quotes them.
- **Today fields are replaced like the rest.** Today's own names, such as the Delivery Note, are no long names and stay.
- **No devlog or TODO commit.** The session's devlog entry carries this Change Set.
