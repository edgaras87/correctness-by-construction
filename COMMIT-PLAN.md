## Decisions taken inside this plan

- **One commit per file family,** as layer 6's plan did; a family
  that runs long splits at its files, as a sub-commit.
- **The rename grep runs over the whole repo,** not below `delivery/`,
  `docs/` and `.claude/` only: commit 14a of layer 6 was that miss.
- **A twin follows in the same commit plan:** where a fix reaches a
  file that has a copy on the other side, the copy is fixed in the
  next commit, and a diff shows the two agree, so DECISION-33's miss
  is not made again.
