# temp/ — this project's scratch space

A place for what this project needs for a while and then drops:
drafts, notes taken while working, a tool's output, what a try
left behind. It is tracked, so what was drafted here shows in
history. A file is deleted once it has served, and git keeps it.

- **Nothing here is a record,** and nothing here is in force. What
  must last moves out: a decision to its record, a tool the project
  keeps to `.claude/`, a fact to where its kind lives.
- **Deliveries arrive here,** as a Delivery Staging: a directory named for the
  Concept Deliverer's commit, its Delivery Note beside it. They are taken as the delivered-copies Agent Rule says
  (`.claude/rules/delivered-copies.md`, rule 5, *After the reply, the Delivery…*). A Delivery Staging is never
  committed. The Delivery Take removes it, and only it.
