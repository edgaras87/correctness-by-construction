# temp/ — drafts and kept files

What lives here is a draft on its way somewhere else, or a file
kept for work still to come.

- **A draft:** a note on its way to a run, a reading written from
  one, a briefing being molded before it goes to a run, an
  evaluation of this repo while the sets that fix it work through
  it.
- **A kept file:** context that work not yet due rests on, such as
  a hand-off a coming reading starts from. A TODO item or the open
  step names it.

Both are tracked, so the shaping shows as diffs. Each is deleted
once it has served, and git history keeps every version.

Not records. Nothing here is the record of anything: what a draft
said and why lives in the records — the devlog logs a draft made,
passed, or deleted; decisions go to the ADRs; the backlog to TODO.

What a note to a run may say is the exchange's,
`docs/conventions/exchange/` §3.7.
