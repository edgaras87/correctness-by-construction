# temp/ — drafts and kept files

What lives here is a draft of a text whose home is elsewhere, or a
file kept for work still to come.

- **A draft:** a Delivery Note not yet staged, a CBC Run Reading of a
  CBC Run, a CBC Run Briefing being written before it goes to a CBC
  Run, the refinement's file, while the Change Sets that fix what it
  found are worked.
- **A kept file:** context that work not yet due rests on, such as
  a CBC Run Hand-off a coming CBC Run Reading starts from. A TODO item or the open
  Plan Step names it.

Both are tracked, so the shaping shows as diffs. Each is deleted
once the work that needed it is done, and git history keeps every version.

Not records. What a draft said and why lives in the records, which
records' list names (`knowledge/backbone-ideas/records.md` §3, *The records*):

- the devlog logs a draft made, passed, or deleted;
- decisions go to the ADRs;
- the backlog goes to TODO.

What a Delivery Note to a CBC Run may say is the Exchange Convention's
(`docs/conventions/exchange/` §3.7, *The Delivery Note*).
