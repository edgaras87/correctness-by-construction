# temp/ — drafts and kept files

What lives here is a draft on its way somewhere else, or a file
kept for work still to come.

- **A draft:** a Delivery Note on its way to a CBC Run, a Run Reading written from
  one, a Run Briefing being molded before it goes to a CBC Run, an
  evaluation of this repo while the sets that fix it work through
  it.
- **A kept file:** context that work not yet due rests on, such as
  a Run Hand-off a coming Run Reading starts from. A TODO item or the open
  Plan Step names it.

Both are tracked, so the shaping shows as diffs. Each is deleted
once it has served, and git history keeps every version.

Not records. Nothing here is the record of anything: what a draft
said and why lives in the records, which the records map lists
(`docs/conventions/project-recording/` §1, *The records at a glance*) — the devlog logs a draft made,
passed, or deleted; decisions go to the ADRs; the backlog to TODO.

What a Delivery Note to a CBC Run may say is the Exchange Convention's
(`docs/conventions/exchange/` §3.7, *The Delivery Note*).
