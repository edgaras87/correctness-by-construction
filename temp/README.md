# temp/ — working drafts

What lives here is a draft on its way somewhere else: a note on its
way to a run, a reading written from one, a briefing being molded
before it goes to a run, an evaluation of this repo while the sets
that fix it work through it. Drafts are tracked, so the shaping
shows as diffs; a draft is deleted once it has served, and git
history keeps every version.

Not records. Nothing here is the record of anything: what a draft
said and why lives in the records — the devlog logs a draft made,
passed, or deleted; decisions go to the ADRs; the backlog to TODO.

What a note to a run may say is the exchange's,
`docs/conventions/exchange/` §3.7.
