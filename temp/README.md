# temp/ — working drafts

Tracked since 2026-09-07 (before that, gitignored as a paste
buffer). What lives here is a draft on its way somewhere else: a
handoff to the handbook, a reply read in from it, a briefing being
molded before it goes to a run. Tracking keeps the shaping visible
as diffs; a draft is deleted once it has served, and git history
keeps every version.

Not records. Nothing here is the record of anything: what a draft
said and why lives in the records — the devlog logs a draft made,
passed, or deleted; decisions go to the ADRs; the backlog to TODO.

One rule for anything that leaves here for a run: no ADR numbers,
paths, or vocabulary of this repo in it — the run cannot see this
repo, and a citation it cannot follow reads as its own.

A second, for anything that names a third repo: give both names.
Our records call a run by its ordinal; a run that has reached its
Identity step calls itself something else, and the other side of
the wall may know it only by that. Neither side's records say so.
The handbook worked out that our "run 3" is its "never-oversold",
got it wrong first, and had the wrong version staged before it was
caught (their note of 2026-09-17). One sentence would have closed
it, and the bridge that used to carry it — the bundle's harvest
lines, which read "never-oversold (run 3 of the pure seed)" — was
deleted the same day (ADR-0022).

The names, while there are few enough to write down:

| ours | its own | where |
|---|---|---|
| run 1 | — (never named itself) | `~/IdeaProjects/cbc-pure-run`, frozen |
| run 2 | — (never named itself) | `~/IdeaProjects/cbc-pure-run-2` |
| run 3 | never-oversold | `~/IdeaProjects/cbc-pure-run-3` |

A run names itself at its Identity step; before that it has only
ours. When this table needs a second column of exceptions it has
outgrown this file.
