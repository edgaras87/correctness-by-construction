Three layers, from general to concrete. Each links only up: a Work
Approach to its project text, a project text to the ideas it draws
on. Never sideways: an idea never points at another idea.

The pattern is the one shared code uses to stay cheap: independent
modules, each saying what it needs and not who gives it, wired
together in one place at the top. Here the ideas are the modules,
and the project text is where they are wired.

## The idea

Written once, bound to no project.

**Holds:**

- **The problem:** what goes wrong without it.
- **The idea:** one sentence.
- **How it works,** in general.
- **Why:** the reasons, and the ways rejected.
- **Limits:** when it costs more than it gives, and when not to use it.
- **Needs:** what it relies on from outside itself, each in its own
  words. Never who gives it: that is the project's wiring.
- **What each project decides:** the open questions the idea leaves to
  the project. A project text answers these, and little else.
- **Changes:** each dated, with why, and from which project.

**Never holds:** a project's name, a path, a tool, a step to follow,
or a pointer to another idea.

## The project text

One concern of one project, drawing on one idea or several.

**Holds:**

- **Draws on:** each idea it uses, with the date of the version it was
  written against, and the parts it uses.
- **Wiring:** each need of each idea, and what in this project meets
  it: another idea, or a local rule.
- **Answers:** one for each thing each idea leaves to the project.
- **Where ideas meet:** each place two ideas pull against each other
  here, and how this project settles it.
- **Local needs:** what this project needs that no idea says, and any
  place it departs from an idea, each with its reason.
- **Cases:** the situations here, each with the Work Approach for it.
- **Lessons waiting:** what was learned here that should go back to an
  idea.

**Never holds:** an idea retold, or steps.

## The Work Approach

What the agent follows. One per case.

**Holds:**

- **Its project text,** one link.
- **When:** the moment it is used.
- **Steps,** short, in order.
- **Done when:** what is true at the end.
- **Stop and ask:** where the reviewer decides.

**Stands alone:** the agent works from this text without reading the
layers above. They serve upkeep, not the task.

**Never holds:** the why. That lives above.

## When something does not fit

Each template has a small fixed core, and room to grow.

1. **Put it under *Other*** first, a section every template allows.
   Nothing else changes.
2. **Seen in three texts of one layer,** the same new section joins
   that template as optional. Texts written before need not change
   until they are next touched.
3. **Seen in every text,** it joins the core.
4. **A text whose whole shape differs** may be a kind of its own: a
   template that keeps the core and adds its own sections. A new kind
   needs three texts that share that shape.

Each template carries a date. A text names the date of the template
it follows.

## Not written by hand

- **The idea map:** which ideas are wired together, and where. Read
  from the project texts' *Draws on* and *Wiring*.
- **A project's list of ideas:** which it took, read the same way.
  Which it left, and which it should take, go under the project's
  own plan.
