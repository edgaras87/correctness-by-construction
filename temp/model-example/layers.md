# What lives in each layer

Three layers, from general to concrete. Each links only up: a Work
Approach to its project version, a project version to its idea. Never
sideways.

## The idea

Written once, bound to no project.

**Holds:**

- **The problem:** what goes wrong without it.
- **The idea:** one sentence.
- **How it works,** in general.
- **Why:** the reasons, and the ways rejected.
- **Limits:** when it costs more than it gives, and when not to use it.
- **What each project decides:** the open questions the idea leaves to
  the project. A project version answers these, and little else.
- **Links to other ideas:** few, each named, each saying what it takes
  from the other.
- **Changes:** each dated, with why, and from which project.

**Never holds:** a project's name, a path, a tool, a step to follow.

## The project version

The idea, for one project. One per idea the project takes.

**Holds:**

- **Its idea,** with the date of the idea it was written against.
- **Answers:** one for each thing the idea leaves to the project.
- **Local needs:** what this project needs that the idea does not say,
  and any place it departs from the idea, each with its reason.
- **Cases:** the situations here the idea meets, each with the Work
  Approach for it.
- **Lessons waiting:** what was learned here that should go back to
  the idea.

**Never holds:** the idea retold, or steps.

## The Work Approach

What the agent follows. One per case.

**Holds:**

- **Its project version,** one link.
- **When:** the moment it is used.
- **Steps,** short, in order.
- **Done when:** what is true at the end.
- **Stop and ask:** where the reviewer decides.

**Stands alone:** the agent works from this text without reading the
layers above. They serve upkeep, not the task.

**Never holds:** the why. That lives above.

## Not drafted here

- **A project's list of ideas:** which it took, which it left, which
  it should take. One per project.
