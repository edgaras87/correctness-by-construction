# 0012. The newborn derives its arrangement; the snippet is withdrawn

Date: 2026-09-02
Status: Accepted (Proposed at the set's open; flipped at its final
records commit, no boundary contradicted it)

## Context

cbc-startup-snippet.md is the bundle's last theory-only artifact:
authored in the archive before any birth, imported verbatim
(2026-08-28), re-derived once for paths — never once checked
against a lived run. Every birth design so far merged it into the
newborn's CLAUDE.md, pre-writing the one section of the agent's
arrangement the agent did not write itself. Its content is not
trivial boilerplate: pointer lines (concept/, two of the five
skills — itself dated), the pre-framing rule, the human-sign-off
gates, four standing guards. Whether an agent booting from
`concept/` would re-derive those rules — or produce something
better, or miss them and suffer for it — has never been observed.

Meanwhile the kit's own model is that the newborn fills its stubs
itself; the merge was our overlay's one write into a kit file, and
the overlay contract's one non-additive clause.

## Options considered

1. Keep shipping it. Rejected: a guess delivered as if earned —
   every other bundle file is harvested from runs or checked
   against the concept; this one is exempt only by habit.
2. Delete it. Rejected: the decision "was the theory right?" needs
   the theory on hand to compare against.
3. Withdraw it from the scenario trial only, manual unchanged.
   Rejected: the manual would still merge what the bundle no
   longer carries; two procedures of record would disagree about
   what a birth is.
4. Withdraw it from the bundle, hold it as a baseline, let the
   newborn derive — chosen.

## Decision

The bundle no longer ships cbc-startup-snippet.md and no birth
merges anything into the newborn's CLAUDE.md. The newborn derives
its own arrangement: the walk opens by reading `concept/`, and the
agent writes CLAUDE.md's CbC section, the README purpose, and the
stub fills itself — the kit's native model, now uniform.

The snippet moves to `docs/baselines/cbc-startup-snippet.md`,
stay-home by location (ADR-0010's structural rule), with a header
naming its role: withheld from births as of 2026-09-02, the
comparison baseline for the first walked birth. It is not shown to
the newborn — same blindness discipline as the safe-reservations-v1
baseline. At the trial's close, the derived section is read against
it and the snippet's fate is decided on evidence: stays (the
derivation missed what it carries), retired (the derivation covered
or bettered it), or merged (each side kept where it won).

The overlay contract tightens: the overlay touches no kit file —
it only adds files in paths the kit does not claim.

## Consequences

Good: the last theory-only artifact becomes a running experiment;
`concept/`'s legibility is tested directly — if the agent cannot
derive a working arrangement from it, that is a concept defect
found cheap; the kit contract loses its only write clause.
Bad: the first derived arrangement may be worse than the snippet —
the human-gate and standing-guard rules are the likely casualties —
and the run pays for it live. Accepted: that outcome is itself the
answer (the snippet earns its place with evidence), the trial's
phase-close readings catch it early, and the run also carries the
scenario's first walk, so attribution between the two experiments
must be argued in the devlog at the boundary where a divergence is
seen, not reconstructed later.
